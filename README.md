# Personal Expense Report 💸

My third Python project.

A beginner Python program that generates a personal expense report using variables, arithmetic operations, strings, type conversions, and string methods.

## Features

* Personal information section
* Five expense categories
* Total and average expense calculations
* Arithmetic operators (`+`, `-`, `*`, `/`, `%`, `//`, `**`)
* String manipulation and slicing
* Type checking and type conversion
* Formatted output using f-strings

## Concepts Practiced

* Variables
* Integers, floats, strings, and booleans
* Arithmetic operators
* String methods
* Indexing and slicing
* Type conversion
* `isinstance()` and `type()`

## Purpose

This project was created while learning Python fundamentals and combining multiple concepts into one complete program.
